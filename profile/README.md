<p>Claude API住宅IP批发与零买不是同一个生意。批量采购谈的是资源承诺、价格阶梯和交付方式，任何一项没写清，量越大越难收场。</p>

<p>先谈资源承诺。多少个地址、覆盖哪些地区、独享还是共享、能否指定城市。这些决定你买到的是什么，比单价重要。</p>

<p>价格阶梯要问清。从多少量开始降价、降多少、按什么周期结算。阶梯表最好写进合同，不要只凭销售口头说。</p>

<p>交付方式影响使用。是一次性导入列表，还是通过接口动态分配。前者适合固定用途，后者适合调度频繁的场景。</p>

<p>验收是批量的关键。抽样核验地址属性，比例可以按批次大小定，但必须有。抽到不符的，要有换货或退款条款。</p>

<p>变更条款在批量场景更敏感。一批地址里如果部分被回收，怎么补、补的是不是同地区、补的时间多长，都要写。</p>

<p>举个假设情形：买了五十个地址，用了一个月发现其中十个的注册信息是机房网段。如果没有验收条款，这十个只能自己认。</p>

<p>还有一个容易被忽略的点：地址的分配密度。同样是五十个地址，分散在五个国家，和集中在两个国家，实际可用性差别很大。按业务地区分布买，不要按总数买。</p>

<p>技术支持的能力也要评估。批量出问题时，能不能一次性排查、能不能提供日志，比单条工单的响应速度更重要。</p>

<p>付款节奏也值得谈。首付比例、尾款条件、是否有账期。批量采购金额大，现金流安排要一起考虑。</p>

<p>成本核算要算全。单价之外还有管理成本、验收成本、变更带来的重配成本。按年算总账，才看得出便宜在哪。</p>

<p>合同期限与退出机制要一起看。长约价格低，但中途调整需求的灵活性差。如果业务还在试错阶段，先签短约更稳。</p>

<p>另外，别把批量当成库存。地址会变、会失效，囤着不用等于浪费。按实际用量分批采购，比一次性买断更灵活。</p>

<p>内部流程也要配套。谁审批采购、谁负责验收、谁维护地址表，职责不清时，出问题往往没人认。</p>

<p>还有一个谈判筹码：长期合作的确定性。承诺用量可以换价格，但要换到条款上，不要只换到口头承诺。</p>

<p>如果采购量跨多个地区，建议分区域签。一个地区出问题，不至于影响整体合同。验收不合格的处理流程要写清：多久内提出、多久内处理、处理不了怎么补偿。</p>
